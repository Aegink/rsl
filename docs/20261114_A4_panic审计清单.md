## 附带发现并修复的隐藏 bug

`analyze/lib.rs` reachable 扫描正则中 `\b` 被历史编辑写成**字面 backspace 控制字符**（`\x08`），
导致 `scan_ctx_http` 的同档函数递归扫描永不命中（ onResponse 递归 http 检测失效）。
已恢复为 `\b`，语义回归正常。

## 残余风险（登记，不阻塞）

- `scraper`/`regex`/`serde_json` 等第三方库内部 panic 无法从源码归零 → 由 CLI 入口 `catch_unwind`
  与 fuzz `convert_full` 目标的外层 catch_unwind 兜底（TASK-BOOK-2 §5.1）。
- `catch_unwind` 不覆盖 `abort` 行为；release profile 未设 `panic="abort"`（已确认）。
