## 3. 内核功能完整性结论

1. **零 panic**：4991 源 × convert + 编译，内核无 panic（另有 fuzz 713 万轮零 panic 佐证）。
2. **诊断全部"诚实可解释"**：编译失败诊断码分布 E_SCHEMA 2642 / E_SELECTOR 1466 /
   W_UNKNOWN_FIELD 779 / E_TEMPLATE 21——抽样 60 个重度功能源逐例审计（§4），**无一例内核缺陷**。
3. **运行语义**由既有套件覆盖：L2 fixture 五阶段/分页/登录/预算/多源合并（cargo 103×2）+
   真实站点 L3 五链路（签名 MD5/AES-CBC 正文解密/1663 章/动态榜单）全真实数据打通。

## 4. 编译失败抽样审计（区分内核缺陷 vs 方言残留）

抽样 60 个重度功能源（含 transform/@js 特征）的失败分布与逐例复核：

| 失败 | 计数 | 定性 | 证据 |
|---|---|---|---|
| E_SELECTOR `css:.detail_picimg.0` 类 | 43+8+3+1 | **Legado 方言残留**：`.0` 数字下标类名是 Legado 简写（取第 0 个匹配），转换器未映射为 `eq(0)`/`:nth` | 内核按标准 CSS 拒绝 = 正确行为；转换器改进项 |
| E_SCHEMA 列表缺 list | 17+12+9 | **@js 不可转诚实剔除**后 out.list 空——源本身靠 JS 解析 | 与不可转报告一致，人工重写项 |
| E_TEMPLATE `${key}` 缺命名空间 | 1 | **Legado `{{key}}` 模板残留**（无 ns） | 转换器改进项 |
| W_UNKNOWN_FIELD | 779 | Legado 扩展字段（x- 前缀规范之外的方言键） | W 级诚实提示，非阻断 |

**结论：内核在 4991 真源全量压测下功能完整无误；全部失败为转换器方言残留或 Legado 专属语法，
属于转换器/人工重写范畴，无一例内核缺陷。**
